# الميل الثاني: تطبيق مدارس الأحد

React + TypeScript + Vite + Tailwind، قاعدة البيانات والدخول على Supabase، والنشر على Vercel.

## الإعداد
1. **Supabase**: شغّل ملفات `supabase/migrations/` بالترتيب (الاسم مرتب بالتاريخ) من SQL Editor.
   - من **Authentication ثم Sign In / Providers ثم Email** اقفل **Confirm email**.
2. **حساب الأدمن**: افتح `supabase/seed_admin.example.sql`، غيّر اسم المستخدم وكلمة السر (12 حرف على الأقل)، شغّله مرة واحدة، وامسح كلمة السر من الملف. ممنوع تحط كلمة سر في الكود.
3. **Vercel** (Settings ثم Environment Variables):
   - `GEMINI_API_KEY` (مطلوب للتحضير بالذكاء الاصطناعي والصوت)
   - `GEMINI_MODEL` (مثلًا `gemini-3.8-flash`)
   - `TTS_MODEL` (اختياري، الافتراضي `gemini-3.8-flash-lite-tts`)
   بعد أي تغيير في المتغيرات اعمل **Redeploy**. حدّث نفس المشروع ما تعملش مشروع جديد، لأن المتغيرات مرتبطة بالمشروع.
4. رابط Supabase والمفتاح العام (publishable) في `src/lib/supabase.ts` و`api/_auth.js`.

## الأمان (على السيرفر مش في الواجهة)
- النجوم والاختبارات والاستبدال و"هات أخوك" وتسميع فارس الإنجيل بتتحسب في دوال Supabase (RPC). المخدوم مش بيكتب النجوم مباشرة (trigger بيمنع).
- الخادم بيشوف ويعدّل مخدومين فصله فقط (RLS)، والأدمن كل الفصول.
- الذكاء الاصطناعي: مفتاح Gemini على السيرفر بس، والدوال بتقبل الخدام والأدمن، وفيه حد يومي لكل خادم (120 وحدة، الأدمن بدون حد).
- إعادة الاختبار بتدّي نجوم على التحسّن عن أحسن نتيجة بس.

## المتصدرون وفارس الإنجيل
- المتصدرون: ترتيب النجوم وفارس الإنجيل والاختبارات والحضور وهات أخوك، بألوان قوس قزح متحركة. الدالة `get_leaderboards` بتبعت الصورة لأول 10 في أي ترتيب بس.
- حلم المخدوم (اختياري) وصورته بيتحفظوا في ملفه، والصورة بتتصغّر 128 بكسل.
- **تعديل النقاط** عند الخادم بيضبط قيمة النقاط لكل نشاط (قداس، اعتراف، مزمور، ساعة أجبية) ومدة الانتظار بين اعترافين (30 يوم افتراضي، بالأيام). الاعتراف ما بيتسجّل تاني للمخدوم قبل انتهاء المدة (والأدمن بيتخطاها). التسجيل ليه تراجع لحد 48 ساعة.
- الخادم بيحدد بداية ونهاية المسابقة. خارج المواعيد الخدام مش بيسجّلوا (الأدمن بيقدر).

## الأوفلاين والمزامنة
- **الدخول:** لو انت داخل بالفعل وفصلت النت، التطبيق بيفضل شغّال ومش بيخرّجك. تسجيل الدخول لأول مرة محتاج نت.
- **القراءة:** أي صفحة فتحتها قبل كده بتفتح أوفلاين بآخر بيانات اتحمّلت.
- **الكتابة:** أي تعديل أوفلاين (حضور، نجوم، تسميع، نقل...) بيتحفظ على الجهاز وبيتبعت لوحده بالترتيب لما النت يرجع. شريط الحالة فوق بيوريك عدد العمليات في الانتظار وأي عملية رفضها السيرفر.
- **محتاجة نت دايمًا:** تغيير اسم المستخدم وكلمة السر، والتحضير بالذكاء الاصطناعي والصوت.
- ممكن عملية تتكرر لو النت قطع بعد ما السيرفر نفّذها وقبل الرد (نادر).

## حدود معروفة
- إجابات الاختبارات الصحيحة بتوصل لمتصفح المخدوم (محتاجة view أو دالة لاحقًا لإخفائها).
- صور الذكاء الاصطناعي من خدمة مجانية خارجية (Pollinations) بحد 15 ثانية تقريبًا بين الصور.
- الصوت داخل البوربوينت تجريبي، ويشتغل في PowerPoint بس.
- مفيش اختبارات تلقائية لحد دلوقتي.

## أوامر
`npm install` ثم `npm run dev` للتطوير، و`npm run build` للبناء، و`npm run typecheck` و`npm run lint` للفحص.
